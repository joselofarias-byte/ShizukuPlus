# ShizukuPlus — JoseloFarias fork

Fork del ecosistema Shizuku mantenido por **JoseloFarias**, orientado a integrar mejoras útiles sobre acceso privilegiado mediante ADB/root sin sacrificar estabilidad ni compatibilidad.

## Objetivos

- Mantener compatibilidad con Android actual y upstream relevante.
- Preservar funciones útiles y eliminar dependencias/telemetría innecesarias cuando corresponda.
- Aplicar mejoras de estabilidad, arranque, permisos y experiencia de uso.
- Mantener atribuciones y licencia del proyecto original.

## Estado

Mantenimiento activo dentro de la familia Shizuku del usuario.

## Desarrollo

```bash
git clone --recurse-submodules https://github.com/joselofarias-byte/ShizukuPlus.git
cd ShizukuPlus
./gradlew :manager:assembleDebug
```
